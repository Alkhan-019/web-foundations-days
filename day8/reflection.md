# Day 8 Reflection

The most difficult concept in this course was understanding how to design systems that remain reliable when many users access them at the same time. Initially, I found it challenging to understand how two customers could attempt to purchase the same seat simultaneously. I overcame this by breaking the problem into smaller steps and learning how database transactions, row locks, and uniqueness constraints help prevent double-booking.

For my capstone project, I would improve the part that needs the most attention based on the feedback I received. I would use that feedback to make the application easier to use, strengthen its functionality, and test the improvements before submitting the project.

Next, I plan to deepen my knowledge of backend development, SQL, API testing, and application deployment. I want to move beyond designing systems on paper and build working applications that demonstrate how the different components interact. I will also continue practising Git and GitHub, writing clear documentation, and testing my code carefully. These skills will help me become a more confident software engineer and prepare me to build reliable applications that can support real users.
